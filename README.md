# Interactive Photo Gallery

An interactive photo gallery built with HTML, CSS, and JavaScript featuring a lightbox display and search functionality.

## Features

- **Responsive Grid Layout**: Photos display in a responsive CSS Grid layout
- **Lightbox Gallery**: Click any photo to view it in a full-screen lightbox with navigation
- **Search Functionality**: Filter photos by caption text using the search bar
- **Mobile Friendly**: Fully responsive design that works on all devices

## Live Demo

🔗 **[View Live Gallery](https://ndumiso-y.github.io/Project5--photogallery/)**

## Technologies Used

- HTML5
- CSS3 (CSS Grid, Flexbox)
- Vanilla JavaScript
- BaguetteBox.js (Lightbox functionality)

## Local Development

1. Clone this repository
2. Open `index.html` in your web browser
3. No build process required - it's a static site!
